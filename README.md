# Sudeepto Mukhopadhyay — Portfolio

A static portfolio built with HTML, CSS, and JavaScript.

## Publishing

GitHub Actions deploys the site to GitHub Pages when a commit is pushed to `main`. In the repository settings, choose **Pages → Build and deployment → GitHub Actions** if Pages has not been enabled yet.

The custom domain is recorded in `CNAME` as `sudeeptom.com`. Update the domain's DNS records to GitHub Pages only after Pages is enabled and the custom domain appears in repository settings. The current Sites DNS configuration remains in effect until you switch it.
